# english-writing

Rules and a review procedure for English written by Korean speakers (slides, abstracts, captions, reports, email). Most problems are not grammar errors but Korean sentence structure carried into English. The goal is technical English that the writer and the audience understand at first reading.

- Rules: translated passives, Korean sentence patterns, one word for one thing, clear references, commas, register, no change to content, format (American spelling, no em/en dashes, non-breaking space between number and unit on slides).
- Procedure: extract all text, read project decisions, list changes before editing, re-check own suggestions, optional independent review, apply only what the user picks, render and check, report.

The skill itself (`skills/english-writing/SKILL.md`) is written in Korean. Examples are in `skills/english-writing/references/examples.md`.
