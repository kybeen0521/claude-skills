# 그림 색 규칙 (figure-colors)

사용자가 고른 색 조합을 고정 값으로 둔다. 그림을 그릴 때마다 색을 새로 찾지 않고, 이 값으로 칠한다. 기준은 두 가지다.

- **AI 티가 없을 것**: RGB 원색(#FF0000, #00FF00, #0000FF 류), matplotlib·Excel 기본 색 순서(tab10 의 #1F77B4 #FF7F0E #2CA02C ...), 무지개(jet, rainbow)를 쓰지 않는다.
- **밤티(촌스러움)가 없을 것**: 채도가 높은 색끼리 붙이지 않고, 미술·자연 팔레트처럼 디자인이 앞서는 색도 쓰지 않는다. 공학·과학 그림용 출처(Paul Tol)와 사용자가 고른 청록 계열만 쓴다.

색은 자동 검사로 "밤티"를 판정할 수 없다. 그래서 아래 값은 **사용자가 실제 자료에서 보고 고른 것**이고, 새 값을 더하는 것도 사용자가 비교 그림을 보고 고른 뒤에만 한다.

## 1. 값

값의 단일 출처는 `scripts/palette.py` 다. 그림 코드에 hex 를 직접 적지 말고 불러 쓴다. 견본은 `assets/swatch.png`.

```python
import sys; sys.path.insert(0, "<이 스킬 폴더>/scripts")
import palette as P
```

### 데이터 클래스가 다를 때 (범주형)

| 이름 | 값 | 쓰는 곳 | 출처 |
|---|---|---|---|
| `P.CAT3` | `#004488` `#DDAA33` `#BB5566` | 범주 2~3개(조건, 평면, 시료 등) | Paul Tol high-contrast |
| `P.VIBRANT[:3]` | `#009988` `#EE7733` `#EE3377` | 점·무리 구분(산점도, parity 의 강조 무리) | Paul Tol vibrant |
| `P.ORDINAL4` | `#81C4E7` `#9398D2` `#906388` `#46353A` | 순서가 있는 무리(각도, 단계, 수준), 밝음 → 어둠 | Paul Tol iridescent 12·16·20·23번째 |
| `P.ACCENT` | `#C00000` | 요구 조건, 목표선, 강조 하나 | 사용자 지정 |
| `P.INK` | `#1A1A1A` | 글자, 축, 검은 선 | |

### 데이터 클래스가 같을 때 (크기, 연속)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `P.teal_cmap("2d")` | `#FFFFFF` → `#628FA2` → `#014460` 의 밝은 쪽 0~70 % | 2D 맵, 채움 등고선 |
| `P.teal_steps(5)` = `P.TEAL_STEPS5` | `#EAF0F3` `#BED0D8` `#91B1BE` `#6591A4` `#497B91` | 단계 채움과 색 막대(단계 가운데 값의 색) |
| `P.teal_cmap("3d")` | 같은 계열의 20~85 %, 투명도 `P.TEAL_3D_ALPHA` = 0.85 | 3D 곡면 |
| `P.TEAL_SOLID` | `#497B91` | 막대 하나, 단색 채움 |

2D 를 70 % 에서 자르는 이유: 끝까지 쓰면 위에 그린 검은 선(유량 선, 등고선)이 묻힌다. 3D 를 20 % 에서 시작하는 이유: 값이 낮은 곡면이 흰색에 가까워져 반투명과 겹치면 사라진다.

## 2. 고르는 순서

1. 이 색이 나타내는 것이 **크기**(값의 높낮이)인가, **무리**인가?
   - 크기 → 청록(`teal_cmap`, `teal_steps`). 범주형 색으로 크기를 칠하지 않는다.
   - 무리 → 2로.
2. 무리에 **순서**가 있는가(0·20·40·60°, 1·2·3단계)?
   - 있음, 4개 이하 → `P.categorical(n, ordered=True)`(ORDINAL4).
   - 있음, 5개 이상 → `teal_steps(n)` 이나, 색을 줄이고 표식 모양·선 모양을 함께 쓴다.
   - 없음 → 3으로.
3. 순서 없는 무리의 수:
   - 2~3개 → `P.CAT3`.
   - 점·무리 강조(나머지는 속 빈 표식이나 회색) → `P.VIBRANT[:3]`.
   - 4개 이상 → `P.VIBRANT` 앞에서부터. **4번째부터(#0077BB, #33BBEE, #CC3311, #BBBBBB)는 사용자가 실제 자료에서 본 적이 없는 값**이라, 처음 쓸 때는 비교 그림을 먼저 보여 준다. `#CC3311` 은 `ACCENT` 와 같은 붉은 계열이라 강조선과 함께 쓰지 않는다.
   - 7개 초과 → 색을 줄이고 표식 모양으로 나눈다.
4. 강조할 것이 하나 있으면 `P.ACCENT`. 다른 붉은 계열과 같은 그림에 두지 않는다.

## 3. 한 자료 안의 일관성

- **같은 색, 같은 모양은 한 자료 안에서 한 가지 뜻으로만** 쓴다. 예: 한 쪽에서 세모 = VIGV 40° 이면 다른 쪽에서도 세모 = 40°. 뜻이 다른 두 그림은 다른 팔레트를 쓴다(예: 평면은 CAT3, 오차 무리는 VIBRANT).
- 같은 변수는 쪽이 바뀌어도 같은 색. 색 막대 단계와 그림 단계도 같은 값(`teal_steps`)을 쓴다.
- 표식은 원, 네모, 세모, 마름모 순서. 선은 실선 기본, 흑백 인쇄를 고려해야 하면 선 모양을 더한다.
- 옅은 색(`#DDAA33`, `#81C4E7`)은 흰 바탕 대비가 낮다. 선은 1.8 pt 이상으로 두껍게, 표식에 진한 테두리를 둔다.

## 4. 예외

- **논문 원고 그림은 흑백(회색조)**. 학회·학술지 양식이 정한 것이 있으면 그것이 이 스킬보다 앞선다.
- 참고문헌에서 가져온 그림은 원래 색 그대로(다시 칠하지 않는다).
- 사용자가 다른 색을 지정하면 그 색을 쓴다. 이 스킬에 더할지는 사용자에게 묻는다.

## 5. 새 색이 필요할 때

1. 먼저 위 값으로 해결되는지 본다(무리를 줄이기, 표식 모양 쓰기).
2. 안 되면 Paul Tol(bright, muted, light, sunset, YlOrBr, iridescent) 안에서 후보 2~3개를 고른다.
3. 후보를 **같은 그림에 칠한 비교 그림**을 보여 주고 사용자가 고른 것만 쓴다.
4. 고른 값은 `scripts/palette.py` 와 이 표에 더하고 날짜를 적는다.

## 6. 쓰지 않는 색 (기각과 이유)

| 색 | 이유 |
|---|---|
| RGB 원색, matplotlib tab10, Excel 기본, jet·rainbow | AI 티(기본값 티) |
| SciencePlots 기본 순서의 `#00B945` `#FF2C00` 등 | 원색에 가까움 |
| 채도 낮은 회청색 계열 | 회색처럼 읽혀 범주가 안 갈림 |
| 밝은 황토·노랑 단독 선 | 흰 바탕 대비 3:1 미만 |
| 녹색과 황토의 조합 | 색각 이상에서 구분 안 됨 |
| 미술·자연 팔레트(MetBrewer, Wes Anderson, ghibli 등) | 공학 그림에는 디자인이 앞섬(사용자 판단) |
| 범주형 색 4개를 밝기가 오르내리는 순서로 순서형 변수에 씀 | 순서가 읽히지 않음 |
| batlow, davos, viridis 등으로 크기 칠하기 | 청록으로 정함 |

- [ ] 크기는 청록, 무리는 범주형으로 나눴는가?
- [ ] 한 자료 안에서 같은 색·모양이 두 뜻으로 쓰이지 않았는가?
- [ ] `ACCENT` 와 다른 붉은 계열이 한 그림에 같이 있지 않은가?
- [ ] VIBRANT 4번째 이후나 새 색을 썼다면 사용자에게 비교 그림을 보였는가?
